## First Look at ReSharper

ReSharper is for people who keep .NET they own in Visual Studio and want one named desk, not mixed inspections. It gives you VS tools, own code, and a short path back to a .NET project you already run. It does not replace Visual Studio. It sits beside Visual Studio and keeps the helpers close.

Work stays on code you keep. Extra solutions wait for their own title.
